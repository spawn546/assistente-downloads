# Assistente: downloads

Assistente de IA que roda no seu próprio computador (Windows 10/11, 64 bits): conversa por texto e voz, Estúdio de imagens, agenda, relatórios de Meta, Google e TikTok Ads, e envio pelo WhatsApp.

## Baixar

Vá em **[Releases](../../releases/latest)** e baixe uma destas opções:

- **`Assistente_<versão>_x64-setup.exe`**: o instalador.
- **`Assistente_<versão>_teste.zip`**: o instalador com o LEIA-ME e as novidades, para quem vai testar.

## Instalar

1. Execute o instalador. Ele instala só para o seu usuário e não pede administrador.
2. O app ainda não tem assinatura digital. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. Na primeira abertura aparece o **setup rápido**: ele analisa o computador e recomenda os modelos, que são baixados dentro do app.

## Requisitos

- Windows 10 ou 11, 64 bits.
- 16 GB de RAM (32 GB recomendado).
- Placa NVIDIA com 6 GB ou mais para a experiência completa. Sem ela, o app usa modelos menores no processador.
- De 3 GB a ~25 GB livres em disco, conforme os modelos escolhidos.

## Reportar problemas

Abra uma **[Issue](../../issues)** contando o que fez, o que esperava e o que aconteceu, com um print se possível. Anexe também os logs da pasta `D:\Assistente\logs` (ou `%LOCALAPPDATA%\Assistente\logs`).
